# Security Policy

## Supported versions

Security fixes are provided for the latest listed public release. Prerelease versions receive best-effort fixes and may change before a stable release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public GitHub issue.

Use the **Contact owners** function on the official NuGet package page and state that the message concerns a private security report:

https://www.nuget.org/packages/LwXLab.Data

Include the affected package and version, target framework and platform, reproduction steps, impact, and any suggested mitigation.

Do not include vulnerability details in any public discussion. Please allow a reasonable remediation period before public disclosure.
